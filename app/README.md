# First app milestone

The Godot project will be added after development access is isolated and an
exact candidate toolchain is selected. This directory is not yet an exportable
project.

Start with GDScript, OpenXR, and the Compatibility renderer. The first scene has
one stationary environment and a simple controller interaction. Baseline startup
and normal exit are required. Additional workloads and measurement calibration
follow the first standalone headset proof.

The first export must record exact Godot, export-template, optional Vendors
plugin, JDK, Android SDK/build-tools, Gradle, ABI, and renderer versions. Retain
the working headset-tested combination. No clock or thermal controls, root,
launcher replacement, or firmware changes belong in this milestone.
